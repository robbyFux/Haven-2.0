<objective>
Fix DetectionZone not persisting when the user draws a zone and taps Save in ZoneEditorScreen.

Purpose: The save button calls `viewModel.saveZone(it)` (a fire-and-forget `viewModelScope.launch`) then immediately calls `onBack()`. Navigation back can clear the ViewModel before the coroutine writes to DataStore, silently discarding the zone.

Root cause: Race condition — `onBack()` fires synchronously after `launch` is queued but before the DataStore `edit` suspension function completes. When the ViewModel is cleared on back-navigation, `viewModelScope` is cancelled, killing the in-flight write.

Fix: Add a `saveZoneAndBack(zone, onBack)` function in the ViewModel that launches the DataStore write and calls `onBack` only inside the coroutine after `setDetectionZone` returns. Similarly wire `clearZoneAndBack`. This keeps navigation responsibility inside a coroutine that cannot be pre-empted by the navigation itself.
Output: Zone is reliably persisted; re-entering ZoneEditorScreen shows the saved zone.
</objective>

  <name>Task 1: Fix save/clear race condition in ZoneEditorViewModel</name>
  <files>app/src/main/java/org/havenapp/main/ui/settings/ZoneEditorViewModel.kt</files>
  <action>
Replace the current `saveZone` and `clearZone` functions with `saveZoneAndBack(zone: DetectionZone, onBack: () -> Unit)` and `clearZoneAndBack(onBack: () -> Unit)`.

Each new function launches a coroutine on `viewModelScope` that:
1. Calls `settingsRepository.setDetectionZone(zone)` (or `null` for clear) — awaits completion
2. Calls `onBack()` on the main thread after the DataStore write succeeds

Use `withContext(Dispatchers.Main) { onBack() }` at the end of each coroutine to ensure the navigation callback runs on the correct dispatcher.

The signature becomes:
```kotlin
fun saveZoneAndBack(zone: DetectionZone, onBack: () -> Unit) {
    viewModelScope.launch {
        settingsRepository.setDetectionZone(zone)
        withContext(Dispatchers.Main) { onBack() }
    }
}

fun clearZoneAndBack(onBack: () -> Unit) {
    viewModelScope.launch {
        settingsRepository.setDetectionZone(null)
        withContext(Dispatchers.Main) { onBack() }
    }
}
```

Add `import kotlinx.coroutines.withContext` and `import kotlinx.coroutines.Dispatchers` if not already present. Remove the old `saveZone` and `clearZone` functions entirely to avoid leaving dead code.
