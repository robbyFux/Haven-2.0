<objective>
Fix two bugs in SignalIntentChannel:

1. Background Activity Start Restriction (Android 10+): `startActivity()` from MonitorService is silently
   dropped by Android. Replace with a system notification whose `contentIntent` is a `PendingIntent` —
   the Signal conversation opens when the user taps the notification, which is a user gesture exempt from
   the restriction.

2. Wrong intent extra: `EXTRA_EMAIL` is ignored by Signal. Replace with `Intent.ACTION_VIEW` + Signal's
   phone-number deep link (`https://signal.me/#p/$recipientNumber`) which opens the correct conversation.

Also add E.164 format validation to `SignalIntentConfigDialog` in SettingsScreen so users get immediate
feedback on malformed phone numbers.

Purpose: Make the SignalIntentChannel actually deliver alerts on real Android 10+ devices.
Output: Working SignalIntentChannel + validated config dialog.
</objective>
