<objective>
Build the Expert Settings UI on top of the foundation from Plan 02.

Purpose: SENSOR-11 — The user can calibrate per-sensor Medium thresholds via sliders.
Low and High values are displayed as derived read-only labels using fixed absolute
offsets. A separate Reset button per sensor clears that one key; a global "Reset all to
defaults" button clears all four. The screen lives at its own `EXPERT_SETTINGS` route,
reachable from the existing Settings screen via a dedicated row — following the same
pattern `ZoneEditorScreen` uses.

Output: Working Expert Settings screen that round-trips through DataStore and survives
app restart. No changes to the sensor pipeline — that was Plan 02's job.
</objective>

    ```kotlin
    package org.havenapp.main.ui.settings

    import androidx.lifecycle.ViewModel
    import androidx.lifecycle.viewModelScope
    import dagger.hilt.android.lifecycle.HiltViewModel
    import kotlinx.coroutines.flow.SharingStarted
    import kotlinx.coroutines.flow.StateFlow
    import kotlinx.coroutines.flow.stateIn
    import kotlinx.coroutines.launch
    import org.havenapp.main.sensor.ExpertThresholdKind
    import org.havenapp.main.sensor.ExpertThresholds
    import org.havenapp.main.storage.SettingsRepository
    import javax.inject.Inject

    @HiltViewModel
    class ExpertSettingsViewModel @Inject constructor(
        private val settingsRepository: SettingsRepository,
    ) : ViewModel() {

        val expertThresholds: StateFlow<ExpertThresholds> = settingsRepository.expertThresholds
            .stateIn(viewModelScope, SharingStarted.WhileSubscribed(5_000), ExpertThresholds.DEFAULT)

        fun setAccelMedium(value: Float?) = viewModelScope.launch {
            settingsRepository.setExpertThreshold(ExpertThresholdKind.ACCEL, value)
        }

        fun setMicMedium(value: Float?) = viewModelScope.launch {
            settingsRepository.setExpertThreshold(ExpertThresholdKind.MIC, value)
        }

        fun setLightMedium(value: Float?) = viewModelScope.launch {
            settingsRepository.setExpertThreshold(ExpertThresholdKind.LIGHT, value)
        }

        fun setCameraMedium(value: Float?) = viewModelScope.launch {
            settingsRepository.setExpertThreshold(ExpertThresholdKind.CAMERA, value)
        }

        fun resetAll() = viewModelScope.launch {
            settingsRepository.resetExpertThresholds()
        }
    }
    ```

    Do NOT include the expert thresholds inside `SettingsUiState` or `SettingsViewModel` — per RESEARCH.md "Anti-Patterns to Avoid", they are a separate concern with their own ViewModel.

    Slider ranges and offsets (these are HARD constants — copy verbatim):

    | Sensor | valueRange | Default Medium | Low offset (+) | High offset (-) | Hard minimum for derived values |
    |--------|-----------|---------------|----------------|-----------------|---------------------------------|
    | Accel  | 0.5f..8.0f | 2.0f | +2.0f | -1.0f | 0.5f |
    | Mic    | 30f..80f   | 55f  | +10f  | -10f  | 20f  |
    | Light  | 5f..150f   | 40f  | +40f  | -20f  | 5f   |
    | Camera | 0.01f..0.30f | 0.08f | +0.10f | -0.05f | 0.01f |

    Derivation rule (pure, no rounding, clamp with `coerceAtLeast(min)`):
    - `derivedLow = (medium + lowOffset).coerceAtLeast(min)`
    - `derivedHigh = (medium - highOffsetAbs).coerceAtLeast(min)` — where `highOffsetAbs` is the absolute value (e.g. 1.0f for Accel)

    For each sensor, the card structure is:
    ```
    Card {
      Column(padding=16.dp, spacedBy=8.dp) {
        Text(title, style = titleMedium)
        Text("Medium: ${formatValue(sliderValue)} $unit", style = bodyMedium, fontFamily = Monospace)
        Slider(
          value = sliderValue,
          onValueChange = { sliderValue = it },
          onValueChangeFinished = { viewModel.setXxxMedium(sliderValue) },
          valueRange = ...,
        )
        Row(spacedBy=16.dp) {
          Text("Low: ${formatValue(derivedLow)} $unit", Monospace)
          Text("High: ${formatValue(derivedHigh)} $unit", Monospace)
        }
        TextButton(onClick = { viewModel.setXxxMedium(null) }) { Text(stringResource(R.string.expert_reset_one)) }
      }
    }
    ```

    Display formatting (helpers local to the file):
    - Accel/Camera: `"%.2f".format(value)`
