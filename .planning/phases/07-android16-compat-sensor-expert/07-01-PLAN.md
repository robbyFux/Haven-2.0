<objective>
Migrate on-device object detection from `tensorflow-lite-task-vision:0.4.4` to
`com.google.mediapipe:tasks-vision:0.10.29` so the app ships 16 KB-aligned native
libraries and no longer shows the Android 16 "not 16 KB compatible" system warning.

Purpose: COMPAT-01 — TFLite Task Vision's prebuilt `libtask_vision_jni.so` has 4 KB ELF
LOAD segment alignment. Android 16 requires 16 KB. MediaPipe Tasks Vision ships
pre-aligned `.so` files. The migration is confined to `HavenObjectDetector.kt` plus the
dependency declaration — all callsites in `CameraAnalyzer` remain untouched because the
public contract of `HavenObjectDetector` is preserved.

Output: Project compiles with MediaPipe; `HavenObjectDetector` loads the existing
`efficientdet_lite0.tflite` via MediaPipe API and returns identical TriggerType results
for person/pet/vehicle labels.
</objective>
