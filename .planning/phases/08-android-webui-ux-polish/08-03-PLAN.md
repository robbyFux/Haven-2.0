```python
@login_required
@require_POST
def device_delete(request, device_id):
    """
    Permanently delete a revoked device row.

    Only the owning user can delete their device. Active devices cannot be deleted —
    returns 403 Forbidden to prevent accidental deletion of live devices.
    HTMX: returns empty 200 response — hx-swap="outerHTML" removes the <tr> from the DOM.
    Non-HTMX fallback: redirects to device_list with a success message.
    """
    device = get_object_or_404(Device, id=device_id, user_id=request.user.id)
    if device.is_active:
        return HttpResponseForbidden("Cannot delete an active device.")
    device.delete()

    if request.htmx:
        return HttpResponse("")  # empty body — HTMX outerHTML swap removes the <tr>

    messages.success(request, f"Device '{device.name}' permanently deleted.")
    return redirect("devices:device_list")
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → admin_panel views | Admin-only SMTP configuration; password field submitted over HTTPS |
| Django views → PostgreSQL | SMTPSettings writes; must use Django ORM (no raw SQL) |
| django_settings.SECRET_KEY → Fernet key | SECRET_KEY used as key material for SMTP password encryption; must not be logged or exposed |
| smtp_test → external SMTP server | Outbound SMTP connection from server; timeout enforced to prevent hang |
| Browser → device_delete view | HTMX POST with device_id; ownership check prevents cross-user deletion |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-07 | Information Disclosure | SMTP password in views.py | mitigate | smtp_password_encrypted stores only Fernet ciphertext; decrypt only for test send; never log plaintext; never include smtp_password_encrypted in GET form initial data |
| T-08-08 | Tampering | smtp_settings POST — unauthorized access | mitigate | @admin_required decorator (same as all other admin_panel views); non-admin users get 403/redirect before reaching view body |
| T-08-09 | Tampering | device_delete POST — wrong user's device | mitigate | get_object_or_404(Device, id=device_id, user_id=request.user.id) — attacker-supplied device_id for another user's device returns 404 |
