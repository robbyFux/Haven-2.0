    - `LoginRequest(BaseModel)`: username (str), password (str), totp_code (str | None = None)

    **server/app/services/jwt.py:**
    - `create_access_token(subject: str) -> str`: encode {"sub": subject, "exp": now+ACCESS_TOKEN_EXPIRE_MINUTES, "type": "access"} with settings.SECRET_KEY, HS256
    - `create_refresh_token(subject: str) -> str`: encode {"sub": subject, "exp": now+REFRESH_TOKEN_EXPIRE_DAYS days, "type": "refresh"} with settings.SECRET_KEY, HS256
    - `decode_token(token: str) -> dict`: decode with python-jose, raise JWTError on failure
    - Import: `from jose import jwt, JWTError`
    - Import: `from datetime import datetime, timedelta, timezone`

    **server/app/services/totp.py:**
    - `generate_totp_secret() -> str`: return `pyotp.random_base32()`
    - `get_totp_uri(secret: str, username: str, issuer: str = "Haven") -> str`: return provisioning_uri
    - `get_totp_qr_png(uri: str) -> bytes`: use qrcode.make, save to BytesIO as PNG, return bytes
    - `verify_totp(secret: str, token: str) -> bool`: return `pyotp.TOTP(secret).verify(token, valid_window=1)`
    - Encrypt/decrypt TOTP secret with Fernet(settings.SECRET_KEY):
      - `encrypt_totp_secret(secret: str) -> str`: Fernet encrypt, return base64 string
      - `decrypt_totp_secret(encrypted: str) -> str`: Fernet decrypt, return plaintext
      - Fernet key derived from settings.SECRET_KEY via SHA256 hash truncated to 32 bytes, then base64url-encoded

    **server/app/dependencies/auth.py:**
    - `oauth2_scheme = OAuth2PasswordBearer(tokenUrl="/api/v1/auth/login")`
    - `async def get_current_user(token: str = Depends(oauth2_scheme), db: DbSession) -> User`:
      - Decode token, verify type=="access", load user by id (sub field), check is_active
      - Raise HTTPException(401) on any failure
    - `async def require_admin(user: User = Depends(get_current_user)) -> User`:
      - Raise HTTPException(403) if not user.is_admin
    - `async def verify_app_key(x_app_key: str = Header(..., alias="X-App-Key"), db: DbSession) -> Device`:
      - Look up Device by app_key, check is_active, update last_seen_at
      - Raise HTTPException(401, "Invalid or inactive App-Key") on failure

    **server/app/routers/auth.py** — `router = APIRouter(tags=["auth"])`:

    `POST /register`:
    - Accept `RegisterRequest` body
    - Check username uniqueness (query DB)
    - Hash password with `passlib.context.CryptContext(schemes=["bcrypt"])` — create `pwd_context` at module level
    - Generate user_key: `f"haven_u_{secrets.token_hex(32)}"`
    - Create User row, commit, return `RegisterResponse` with id, username, user_key

    `POST /login`:
    - Accept `LoginRequest` body
    - Find user by username, verify password with pwd_context.verify()
    - If user.totp_enabled: require totp_code in request, verify with decrypt_totp_secret + verify_totp
    - If 2FA required but code missing: return 401 with `{"detail": "TOTP code required", "totp_required": true}`
    - On success: return `TokenResponse` with access_token + refresh_token (subject = str(user.id))

    `POST /refresh`:
    - Accept `RefreshRequest` body
    - Decode refresh_token, verify type=="refresh"
    - Return new `TokenResponse` with fresh access + refresh tokens

    `GET /me`:
    - Requires `get_current_user` dependency
    - Return `UserResponse`

    `POST /2fa/setup`:
    - Requires `get_current_user`
    - Generate TOTP secret, store encrypted in user.totp_secret (do NOT enable yet)
    - Return `TotpSetupResponse` with secret and QR code PNG as base64

    `POST /2fa/verify`:
    - Requires `get_current_user`
    - Accept `TotpVerifyRequest`, verify code against stored secret
    - On success: set user.totp_enabled = True, commit
    - Return 200 `{"status": "2fa_enabled"}`
