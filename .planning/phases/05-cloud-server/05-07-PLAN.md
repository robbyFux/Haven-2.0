    **server/app/services/notify.py:**

    `async def send_email(to: str, subject: str, body: str) -> bool`:
    - Use aiosmtplib: `from aiosmtplib import send as smtp_send` or manual SMTP connect
    - Connect to settings.SMTP_HOST:SMTP_PORT with STARTTLS
    - Authenticate with settings.SMTP_USER, SMTP_PASSWORD
    - Build MIMEText message with From=settings.SMTP_FROM, To=to, Subject=subject
    - Send, return True on success, False on error (log error, don't raise)

    `def send_signal(recipient: str, message: str) -> bool`:
    - Synchronous (called from Celery task)
    - POST to `{settings.SIGNAL_API_URL}/v2/send` with JSON:
      `{"message": message, "number": settings.SIGNAL_SENDER, "recipients": [recipient]}`
    - Headers: Content-Type application/json, Authorization Bearer {settings.SIGNAL_AUTH_TOKEN} if set
    - Use httpx.Client, timeout 10s
    - Return True on 200-201, False on error

    `def send_pushover(user_key: str, message: str, title: str = "Haven Alert") -> bool`:
    - Synchronous (called from Celery task)
    - POST to `https://api.pushover.net/1/messages.json` with form data:
      token=settings.PUSHOVER_APP_TOKEN, user=user_key, message=message, title=title
    - Use httpx.Client, timeout 10s
    - Return True on 200, False on error

    `def format_notification_message(event_type: str, severity: str, timestamp: str, device_name: str, analysis_summary: str | None) -> tuple[str, str]`:
    - Return (subject, body) tuple
    - Subject: f"Haven Alert: {severity} {event_type} on {device_name}"
    - Body: formatted text with all fields, including analysis summary if available

    - `from app.celery_app import celery_app`

    - `@celery_app.task(name="send_notification")`:
    - `def send_notification_task(event_id: int) -> dict`:
      - Load event + user + device + analysis_result from DB (use asyncio.run with async session)
      - If not user.notifications_enabled: return {"status": "disabled"}
      - Format message via format_notification_message(event_type, severity, timestamp, device.name, analysis_summary)
      - results = {}
      - If user.notification_email and settings.SMTP_HOST:
        - `results["email"] = asyncio.run(send_email(user.notification_email, subject, body))`
      - If user.notification_signal_number and settings.SIGNAL_API_URL:
        - `results["signal"] = send_signal(user.notification_signal_number, body)`
      - If user.pushover_user_key and settings.PUSHOVER_APP_TOKEN:
        - `results["pushover"] = send_pushover(user.pushover_user_key, body, subject)`
      - Return {"status": "sent", "results": results}
