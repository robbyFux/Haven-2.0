    **server/app/schemas/admin.py** — Pydantic v2:
    - `UserAdminResponse(BaseModel)`: id, username, is_admin, is_active, totp_enabled, storage_quota_mb, max_events, current_storage_bytes, current_event_count, device_count (int), created_at, model_config from_attributes=True
    - `UserListResponse(BaseModel)`: users (list[UserAdminResponse]), total (int)
    - `QuotaUpdateRequest(BaseModel)`: storage_quota_mb (int | None = None, ge=0), max_events (int | None = None, ge=0)
    - `SystemStatsResponse(BaseModel)`: total_users (int), total_events (int), total_devices (int), total_storage_bytes (int)

    **server/app/routers/admin.py** — `router = APIRouter(tags=["admin"])`:

    `GET /users`:
    - Requires require_admin
    - Query all users with count of devices (subquery or relationship)
    - Return UserListResponse

    `GET /users/{user_id}`:
    - Requires require_admin
    - Return UserAdminResponse, 404 if not found

    `PATCH /users/{user_id}/quota`:
    - Requires require_admin
    - Accept QuotaUpdateRequest
    - Update only provided fields (if storage_quota_mb is not None, update it; same for max_events)
    - Commit, return updated UserAdminResponse

    `PATCH /users/{user_id}/admin`:
    - Requires require_admin
    - Body: `{"is_admin": bool}`
    - Toggle admin status, commit
    - Return UserAdminResponse

    `DELETE /users/{user_id}`:
    - Requires require_admin
    - Prevent self-deletion (403)
    - Deactivate user (is_active=False), commit
    - Return 200

    `GET /stats`:
    - Requires require_admin
    - Count total users, events, devices, sum storage bytes
    - Return SystemStatsResponse
