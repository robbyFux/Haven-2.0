    **server/app/ml/detector.py:**
    - Module-level `_detector: HavenDetector | None = None`
    - `def get_detector() -> HavenDetector | None`:
      - If settings.AI_BACKEND != "tflite": return None
      - If _detector is None: create HavenDetector(), store in _detector
      - Return _detector

    - `class HavenDetector`:
      - `__init__(self)`:
        - `from ai_edge_litert.interpreter import Interpreter` (inside __init__ to avoid import error when TFLite not installed)
        - `self._interpreter = Interpreter(model_path=str(settings.TFLITE_MODEL_PATH))`
        - `self._interpreter.allocate_tensors()`
        - `self._input_details = self._interpreter.get_input_details()`
        - `self._output_details = self._interpreter.get_output_details()`
      - `def detect(self, image_bytes: bytes) -> list[dict]`:
        - Decode bytes to PIL Image, resize to model input shape (320x320 for EfficientDet Lite 0)
        - Convert to numpy array, normalize to uint8
        - set_tensor(input), invoke(), get_tensor(outputs)
        - Parse EfficientDet output format: boxes, classes, scores, count
        - Return list of dicts: {"label": class_name, "confidence": float, "bbox": [y1,x1,y2,x2]}
        - Filter by confidence threshold 0.3
        - Class labels: {0: "person", 1: "bicycle", 2: "car", 3: "motorcycle", ...} (COCO labels subset)

    **server/app/ml/openrouter.py:**
    - `def analyze_frame_openrouter(jpeg_bytes: bytes, model: str, api_key: str) -> dict`:
      - Use `httpx.Client` (synchronous — called from Celery sync context)
      - Encode jpeg_bytes to base64
      - POST to `https://openrouter.ai/api/v1/chat/completions` with:
        - headers: Authorization Bearer, Content-Type application/json
        - body: model, messages with text prompt + base64 image_url
        - Prompt: "Analyze this security camera frame. Describe any persons, objects, or unusual activity. Respond with JSON: {\"labels\": [\"person\", ...], \"description\": \"...\"}"
      - Parse response: extract content from choices[0].message.content
      - Try to parse content as JSON, fallback to {"labels": [], "description": content}
      - Return dict with labels, description
      - Timeout: 30 seconds
      - On error: return {"labels": [], "description": f"Analysis failed: {error}"}

    **server/app/ml/__init__.py:** empty (already exists from Plan 01)
