    **server/app/schemas/event.py** — Pydantic v2:
    - `EventCreateSchema(BaseModel)`: event_type (str), severity (str, pattern="^(LOW|MEDIUM|HIGH|CRITICAL)$"), timestamp (datetime), sensor_value (float | None = None), triggers (list[TriggerSchema] | None = None)
    - `TriggerSchema(BaseModel)`: trigger_type (str), sensor_value (float | None = None)
    - `EventResponse(BaseModel)`: id, event_type, severity, timestamp, sensor_value, media_path (str|None), has_analysis (bool), device_name (str), created_at, model_config from_attributes=True
    - `EventListResponse(BaseModel)`: events (list[EventResponse]), total (int), page (int), page_size (int)

    **server/app/services/storage.py:**
    - `from app.config import settings`
    - `import aiofiles, os`
    - `async def save_media(user_id: int, event_id: int, data: bytes, filename: str) -> str`:
      - Create directory: `{MEDIA_ROOT}/{user_id}/{event_id}/`
      - Write data to `{dir}/{filename}` using aiofiles
      - Return relative path from MEDIA_ROOT
    - `async def load_media(path: str) -> bytes`:
      - Read from `{MEDIA_ROOT}/{path}` using aiofiles
      - Return bytes
    - `async def delete_media(path: str) -> None`:
      - Remove file at `{MEDIA_ROOT}/{path}` if exists

    **server/app/dependencies/quota.py:**
    - `async def get_user_for_device(device: Device = Depends(verify_app_key), db: DbSession) -> User`:
      - Load user by device.user_id
    - `def check_storage_quota(user: User, additional_bytes: int) -> None`:
      - If `user.current_storage_bytes + additional_bytes > user.storage_quota_mb * 1024 * 1024`: raise HTTPException(413, "Storage quota exceeded")
    - `def check_event_quota(user: User) -> None`:
      - If `user.current_event_count >= user.max_events`: raise HTTPException(429, "Event count quota exceeded")

    **server/app/routers/events.py** — `router = APIRouter(tags=["events"])`:

    `POST /devices/{app_key}/events`:
    - Parameters: app_key (path), metadata (Form as JSON string), video (UploadFile | None = File(None))
    - Dependencies: device via verify_app_key (use X-App-Key header AND path param — validate they match)
    - Parse metadata JSON into EventCreateSchema
    - Load user via device.user_id
    - Check event quota (check_event_quota)
    - If video provided:
      - Read video bytes in chunks, accumulate, check MAX size (50MB default)
      - Check storage quota (check_storage_quota with video size)
      - If X-Encryption-Password header present: derive key via derive_key(password, user.username), encrypt_file(video_bytes, key), set is_encrypted=True
      - Save via storage.save_media()
    - Create Event row + EventTrigger rows if triggers provided
    - Update user.current_storage_bytes += media_size, user.current_event_count += 1
    - Commit
    - If AI_BACKEND != "none": enqueue Celery task `analyze_event_task.delay(event_id, media_path, encryption_key_hex)` where encryption_key_hex = key.hex() if encrypted, else None
    - Return 201, EventResponse

    `GET /events`:
    - Requires get_current_user
    - Query params: page (int=1), page_size (int=20, max=100), device_id (int|None), severity (str|None)
    - Return EventListResponse with pagination

    `GET /events/{event_id}`:
    - Requires get_current_user
    - Return EventResponse, 404 if not found or not owned

    `DELETE /events/{event_id}`:
    - Requires get_current_user
    - Delete media file, update user quotas, delete Event (cascade triggers+analysis)
    - Return 200

    **Update server/app/main.py:**
    - Wire events router at appropriate prefix. The upload endpoint is at `/api/v1/devices/{app_key}/events` so include events router at `/api/v1` prefix level with the events router handling both `/devices/{app_key}/events` and `/events` paths internally.
