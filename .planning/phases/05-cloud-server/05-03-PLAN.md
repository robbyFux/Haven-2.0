    **server/app/services/crypto.py:**
    - `from argon2.low_level import hash_secret_raw, Type`
    - `from cryptography.hazmat.primitives.ciphers.aead import AESGCM`
    - Constants: ARGON2_TIME_COST=2, ARGON2_MEMORY_COST=65536 (64MB), ARGON2_PARALLELISM=2, ARGON2_HASH_LEN=32
    - `def derive_key(password: str, username: str) -> bytes`:
      - salt = `username.lower().encode("utf-8").ljust(16, b"\\x00")[:16]` (16-byte deterministic salt)
      - Return `hash_secret_raw(secret=password.encode("utf-8"), salt=salt, time_cost=..., memory_cost=..., parallelism=..., hash_len=32, type=Type.ID)`
    - `def encrypt_file(data: bytes, key: bytes) -> bytes`:
      - `nonce = os.urandom(12)`
      - `ct = AESGCM(key).encrypt(nonce, data, None)`
      - Return `nonce + ct` (12-byte nonce prepended)
    - `def decrypt_file(data: bytes, key: bytes) -> bytes`:
      - `nonce, ct = data[:12], data[12:]`
      - Return `AESGCM(key).decrypt(nonce, ct, None)`

    **server/app/schemas/device.py** — Pydantic v2:
    - `DeviceCreateRequest(BaseModel)`: name (str, min_length=1, max_length=100)
    - `DeviceResponse(BaseModel)`: id (int), name (str), app_key (str), is_active (bool), created_at (datetime), last_seen_at (datetime | None), model_config with from_attributes=True
    - `DeviceListResponse(BaseModel)`: devices (list[DeviceResponse])

    **server/app/routers/devices.py** — `router = APIRouter(tags=["devices"])`:

    `POST /` — Create device:
    - Requires `get_current_user`
    - Accept `DeviceCreateRequest`
    - Generate app_key: `f"hav_{secrets.token_hex(32)}"`
    - Create Device row (user_id=user.id, name=body.name, app_key=app_key)
    - Return 201, `DeviceResponse` (include app_key — only shown once on create)

    `GET /` — List user's devices:
    - Requires `get_current_user`
    - Query devices where user_id==user.id, order by created_at desc
    - Return `DeviceListResponse`

    `GET /{device_id}` — Get single device:
    - Requires `get_current_user`
    - Return 404 if not found or not owned by user

    `DELETE /{device_id}` — Revoke device:
    - Requires `get_current_user`
    - Set is_active=False (soft delete), commit
    - Return 200 `{"status": "revoked"}`

    **Update server/app/main.py:**
    - Add: `app.include_router(devices.router, prefix="/api/v1/devices", tags=["devices"])`
