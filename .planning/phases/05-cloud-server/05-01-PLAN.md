    - `Base = DeclarativeBase()` from `sqlalchemy.orm`
    - Common mixin `TimestampMixin` with `created_at` (server_default=func.now()) and `updated_at` (onupdate=func.now())

    **server/app/models/user.py — class User(TimestampMixin, Base):**
    - `__tablename__ = "users"`
    - `id`: Integer, primary_key, autoincrement
    - `username`: String(50), unique, index, not null
    - `password_hash`: String(255), not null (bcrypt hash)
    - `user_key`: String(64), unique, index, not null (long-lived API key, format: `haven_u_<32hex>`)
    - `is_admin`: Boolean, default=False
    - `is_active`: Boolean, default=True
    - `totp_secret`: String(255), nullable (encrypted with server SECRET_KEY via Fernet)
    - `totp_enabled`: Boolean, default=False
    - `storage_quota_mb`: Integer, default=1024 (admin-settable, per CLOUD-05)
    - `max_events`: Integer, default=10000 (admin-settable, per CLOUD-05)
    - `current_storage_bytes`: BigInteger, default=0
    - `current_event_count`: Integer, default=0
    - Relationships: `devices` (one-to-many Device), `events` (one-to-many Event)
    - `notification_email`: String(255), nullable
    - `notification_signal_number`: String(20), nullable
    - `pushover_user_key`: String(50), nullable
    - `notifications_enabled`: Boolean, default=True

    **server/app/models/device.py — class Device(TimestampMixin, Base):**
    - `__tablename__ = "devices"`
    - `id`: Integer, primary_key
    - `user_id`: Integer, ForeignKey("users.id"), not null, index
    - `app_key`: String(68), unique, index, not null (format: `hav_<32hex>`)
    - `name`: String(100), not null (human-readable device name)
    - `is_active`: Boolean, default=True
    - `last_seen_at`: DateTime, nullable
    - Relationship: `user` (many-to-one User), `events` (one-to-many Event)

    **server/app/models/event.py — class Event(TimestampMixin, Base):**
    - `__tablename__ = "events"`
    - `id`: Integer, primary_key
    - `user_id`: Integer, ForeignKey("users.id"), not null, index
    - `device_id`: Integer, ForeignKey("devices.id"), not null, index
    - `event_type`: String(50), not null (e.g. "CAMERA", "ACCELEROMETER")
    - `severity`: String(20), not null (LOW/MEDIUM/HIGH/CRITICAL)
    - `timestamp`: DateTime, not null
    - `sensor_value`: Float, nullable
    - `media_path`: String(500), nullable (path to encrypted video)
    - `media_size_bytes`: BigInteger, nullable
    - `is_encrypted`: Boolean, default=False
    - Relationships: `triggers` (one-to-many EventTrigger), `analysis_result` (one-to-one)

    **class EventTrigger(TimestampMixin, Base):**
    - `__tablename__ = "event_triggers"`
    - `id`: Integer, primary_key
    - `event_id`: Integer, ForeignKey("events.id", ondelete="CASCADE"), not null
    - `trigger_type`: String(50), not null
    - `sensor_value`: Float, nullable
    - `media_path`: String(500), nullable

    **class AnalysisResult(TimestampMixin, Base):**
    - `__tablename__ = "analysis_results"`
    - `id`: Integer, primary_key
    - `event_id`: Integer, ForeignKey("events.id", ondelete="CASCADE"), unique, not null
    - `backend`: String(20), not null ("tflite" or "openrouter")
    - `labels`: Text, nullable (JSON string of detected labels)
    - `confidence`: Float, nullable
    - `description`: Text, nullable (AI-generated description)
    - `raw_result`: Text, nullable (full JSON response)
