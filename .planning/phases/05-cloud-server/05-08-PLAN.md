<!-- Server API contract from Plan 05-04 -->
Upload endpoint: POST /api/v1/devices/{app_key}/events
- Auth: X-App-Key header
- Body: multipart/form-data with fields: metadata (JSON string), video (optional file)
- metadata JSON: { event_type: string, severity: string, timestamp: ISO datetime, sensor_value: float|null }
- Response: 201 on success

Heartbeat endpoint: POST /api/v1/devices/{app_key}/heartbeat
- Auth: X-App-Key header
- Body: JSON { message: string }
- Response: 200 on success

    **app/src/main/java/org/havenapp/main/notify/CloudChannel.kt:**

    Create `CloudChannel` implementing `HavenAlertChannel`. Follow the exact same pattern as `PushoverChannel`:
    - Constructor: `CloudChannel(private val httpClient: OkHttpClient, private val serverUrl: String, private val appKey: String)`
    - `override val id: String = "cloud"`
    - `override val isEnabled: Boolean = serverUrl.isNotBlank() && appKey.isNotBlank()`

    `override suspend fun send(event: TriggerEvent, attachment: ByteArray?): Result<Unit>`:
    - Use `withContext(Dispatchers.IO)` + `runCatching` (same as PushoverChannel)
    - Build URL: `"${serverUrl.trimEnd('/')}/api/v1/devices/$appKey/events"`
    - Build multipart body (`MultipartBody.Builder().setType(MultipartBody.FORM)`):
      - `.addFormDataPart("event_type", event.type.name)`
      - `.addFormDataPart("severity", event.severity.name)`
      - `.addFormDataPart("timestamp", java.time.Instant.ofEpochMilli(event.timestamp).toString())`
      - `.addFormDataPart("sensor_value", (event.sensorValue ?: 0f).toString())`
      - If `attachment != null`: `.addFormDataPart("media", "alert.jpg", attachment.toRequestBody("image/jpeg".toMediaType()))`
    - Build request with `.header("X-App-Key", appKey)` and `.post(body)`
    - Execute, check `response.isSuccessful`, throw on failure with error code + body

    `override suspend fun sendHeartbeat(message: String): Result<Unit>`:
    - URL: `"${serverUrl.trimEnd('/')}/api/v1/devices/$appKey/heartbeat"`
    - JSON body: `{"message": "$message"}` using `message.toRequestBody("application/json".toMediaType())`
      - Actually build proper JSON: `"""{"message":"${message.replace("\"", "\\\"")}"}"""`
      - Or use a simple approach: `okhttp3.FormBody` is not right here. Use `RequestBody.create` with JSON media type.
    - Header: `X-App-Key: $appKey`
    - POST, check isSuccessful

    KDoc: Class-level doc explaining purpose, URL pattern, auth mechanism. Match PushoverChannel doc style.

    Imports needed: `kotlinx.coroutines.Dispatchers`, `kotlinx.coroutines.withContext`, `okhttp3.*`, `okhttp3.MediaType.Companion.toMediaType`, `okhttp3.RequestBody.Companion.toRequestBody`, `org.havenapp.main.events.TriggerEvent`
