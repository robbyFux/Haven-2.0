2. Create notifications/views.py:
   - notification_settings(request): @login_required
     GET: populate form from request.user's current notification fields
       form = NotificationSettingsForm(initial={
         "notifications_enabled": request.user.notifications_enabled,
         "notification_email": request.user.notification_email or "",
         "notification_signal_number": request.user.notification_signal_number or "",
         "pushover_user_key": request.user.pushover_user_key or "",
       })
       Render notifications/settings.html

     POST: validate form
       If valid:
         user = request.user
         user.notifications_enabled = form.cleaned_data["notifications_enabled"]
         user.notification_email = form.cleaned_data["notification_email"] or None
         user.notification_signal_number = form.cleaned_data["notification_signal_number"] or None
         user.pushover_user_key = form.cleaned_data["pushover_user_key"] or None
         user.save(update_fields=["notifications_enabled", "notification_email",
                                  "notification_signal_number", "pushover_user_key"])
         messages.success(request, "Notification settings saved.")
         If request.htmx: render partials/notification_form.html (form + success banner)
         Else: redirect to notifications:settings
       If invalid:
         If request.htmx: render partials/notification_form.html with errors
         Else: render settings.html with form errors
