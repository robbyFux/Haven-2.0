  <action>
1. Create devices/forms.py:
   - DeviceCreateForm(forms.Form): name (CharField max_length=100, required=True, label="Device Name")

2. Create devices/views.py:
   - All views decorated with @login_required

   - device_list(request):
     devices = Device.objects.filter(user_id=request.user.id).order_by("-created_at")
     If request.htmx: render partials/device_table.html
     Else: render devices/list.html with devices + DeviceCreateForm

   - device_create(request):
     POST only. Validate DeviceCreateForm.
     Create Device: user_id=request.user.id, name=form.cleaned_data["name"], app_key=f"hav_{secrets.token_hex(32)}", is_active=True
     Add success message with the generated app_key (shown once, user must copy it).
     Redirect to device_list.

   - device_revoke(request, device_id):
     POST only. Get Device by id + user_id=request.user.id (404 if not found or not owned).
     Set is_active=False, save.
     If request.htmx: return render of partials/device_row.html with updated device (row replacement).
     Else: redirect to device_list with success message.

3. Create devices/urls.py:
   - app_name = "devices"
   - paths: "" (list), "create/" (create), "<int:device_id>/revoke/" (revoke)

4. Create templates:
   - list.html (extends base.html):
     Title: "Devices"
     Create form at top: single name input + "Add Device" teal button, POST to create URL
     Device table below (include device_table.html partial)
     If messages contain app_key: show in a green alert box with monospace font + copy hint

   - partials/device_table.html:
     Table with columns: Name, App-Key (first 12 chars + "..."), Status (Active/Revoked badge), Last Seen, Created, Actions
     Each row: include device_row.html
     Empty state: "No devices yet" message

   - partials/device_row.html:
     <tr id="device-{{ device.id }}"> with device data
     Active badge: green (bg-green-900/50 text-green-400)
     Revoked badge: red (bg-red-900/50 text-red-400)
     Actions: if is_active: "Revoke" button with hx-post to revoke URL, hx-target="#device-{{ device.id }}", hx-swap="outerHTML", hx-confirm="Revoke this device?"
     App-key display: monospace, truncated

   Tailwind styling: table with bg-gray-800 rows, border-gray-700, hover:bg-gray-750. Consistent with dark theme from base.html.

5. Write tests in tests/test_devices.py using conftest fixtures.
   For test_device_revoke_other_user: create two users, one device for user2, user1 tries to revoke -> 404.
   For test_device_list_htmx_partial: set HTTP_HX_REQUEST header in client.get().
