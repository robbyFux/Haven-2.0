    - test_totp_setup_generates_qr: GET /accounts/2fa-setup/ (logged in) -> page contains QR code image (base64 PNG)
    - test_totp_setup_confirm: POST /accounts/2fa-setup/ with valid code -> totp_enabled=True
    - test_logout: POST /accounts/logout/ -> session cleared, redirect to login

  <action>
1. Create accounts/forms.py:
   - RegisterForm(forms.Form): username (CharField max_length=50), password (CharField widget=PasswordInput), password_confirm (CharField widget=PasswordInput). clean() validates passwords match and username uniqueness.
   - LoginForm(forms.Form): username, password (PasswordInput)
   - TotpForm(forms.Form): code (CharField max_length=6, min_length=6)
   - TotpSetupConfirmForm(forms.Form): code (CharField max_length=6, min_length=6)

2. Create accounts/views.py:
   - register_view(request):
     GET: render register.html with RegisterForm
     POST: validate form, create HavenUser with pwd_context.hash(password), user_key=f"haven_u_{secrets.token_hex(32)}", redirect to login with success message.
     Check HAVEN_OPEN_REGISTRATION env var (default "true"). If "false", return 403.

   - login_view(request):
     GET: render login.html with LoginForm
     POST: validate, call authenticate(request, username, password).
       If None: add error "Invalid credentials".
       If user.totp_enabled: store user.id in session["pending_2fa_user_id"], redirect to totp_verify.
       Else: call login(request, user, backend="core.auth_backend.HavenAuthBackend"), redirect to LOGIN_REDIRECT_URL.

   - totp_verify_view(request):
     Guard: if "pending_2fa_user_id" not in session, redirect to login.
     GET: render totp_verify.html with TotpForm
     POST: validate code against decrypt_totp_secret(user.totp_secret) via verify_totp().
       If valid: call login(request, user, backend=...), delete session key, redirect to /events/.
       If invalid: form error.

   - totp_setup_view(request): @login_required
     GET: generate secret, store in session["pending_totp_secret"]. Generate QR PNG, render totp_setup.html with base64 QR image and secret string.
     POST: validate TotpSetupConfirmForm code against session["pending_totp_secret"]. If valid: encrypt secret, save to user.totp_secret, set totp_enabled=True, save, redirect to profile with success message.

   - profile_view(request): @login_required
     Render profile.html showing username, 2FA status, links to change password / 2FA setup / delete account.

   - logout_view(request):
     POST only. Call django.contrib.auth.logout(request), redirect to login.

3. Create accounts/urls.py:
   - app_name = "accounts"
   - paths: login/, register/, logout/, totp-verify/, 2fa-setup/, profile/

4. Create templates (all extend base.html, use Tailwind dark theme):
   - login.html: form with username + password fields, submit button, link to register
   - register.html: form with username + password + password_confirm, submit, link to login
   - totp_verify.html: form with single 6-digit code input, large centered card
   - totp_setup.html: QR code image (base64 inline), manual secret display, code confirmation input
   - profile.html: username, 2FA status badge, links to actions

   Template styling: all forms use Tailwind classes (bg-gray-800 cards, rounded-lg, px-6 py-4 inputs with bg-gray-700 border-gray-600 text-white, teal-600 submit buttons). Input fields: w-full px-4 py-2 bg-gray-700 border border-gray-600 rounded-lg text-white focus:border-teal-500 focus:ring-teal-500. Buttons: bg-teal-600 hover:bg-teal-700 text-white font-medium py-2 px-6 rounded-lg.

5. Write tests in tests/test_accounts.py matching all behaviors listed above. Use the conftest fixtures (create_user, authenticated_client). For TOTP tests: use pyotp.TOTP(secret).now() to generate valid codes.
