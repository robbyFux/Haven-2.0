    ```kotlin
    // Capture JPEG for notification attachment (D-12, < 200 KB at quality 60)
    runCatching {
        val out = ByteArrayOutputStream()
        val nv21 = ByteArray(width * height * 3 / 2)
        luma.copyInto(nv21, destinationOffset = 0)
        // UV planes: create grayscale NV21 (0x80 = neutral chroma)
        java.util.Arrays.fill(nv21, width * height, nv21.size, 0x80.toByte())
        YuvImage(nv21, ImageFormat.NV21, width, height, null)
            .compressToJpeg(Rect(0, 0, width, height), 60, out)
        lastJpegFrame = out.toByteArray()
    }
    ```

    Note: This creates a grayscale JPEG from the luma plane with neutral chroma, which is acceptable for alert thumbnails. Using the full-color buildBitmap approach would require access to the UV planes which are extracted later in that method — the grayscale approach avoids duplicating that code and keeps the frame capture lightweight.

    Alternative (preferred if the image variable is still open): if `image.planes` is still accessible at this point in the `image.use {}` block (which it is), build a proper NV21 from all three planes. Read the existing `buildBitmap` method to see the UV extraction pattern and replicate it inline for the JPEG capture, using quality 60 instead of 75.
